# Discord-бот

Бот работает на Node.js 18+ и использует `discord.js`.

## Настройка и запуск

1. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications), добавьте к нему бота и скопируйте его токен.
2. Включите для приложения slash-команды и пригласите бота на сервер с областями `bot` и `applications.commands`. Боту нужно право отправлять сообщения в нужном канале.
3. Задайте переменные окружения:
   - `BOT_TOKEN` — токен бота.
   - `CLIENT_ID` — Application ID приложения из Developer Portal.
   - `GUILD_ID` — необязательно: ID тестового сервера. Если задан, команда регистрируется на этом сервере и становится доступна быстрее; без него команда регистрируется глобально.
4. Запустите командой `npm start`.

На хостинге укажите Node.js 18 или новее, команду запуска `npm start` и переменные окружения в настройках проекта. Не публикуйте токен и не добавляйте его в исходный код.

## Команда

- `/сказать текст` — отправляет указанный текст в канал от имени бота.

Вызывать команду могут только администраторы сервера. Упоминания `@everyone`, ролей и пользователей в отправленном тексте отключены.
